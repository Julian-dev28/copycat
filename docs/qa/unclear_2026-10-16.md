# The "unclear" sweep, 2026-10-16

Julien's ask, verbatim: "whats the point of index here? seems unclear, maybe do a qa overview of this and
see what other unclear things there are within the app". Trigger: the Trade page's wallet list header read
`TRADER | INDEX | 2… | 7d`.

## Method

Regenerated the visual sweep (`E2E_SWEEP=1 npx playwright test --project=visual -g sweep`, 42 PNGs,
every page at 1440 and 390, dark and light, demo fixtures) and read every 1440 dark capture; viewport
captures of Trade, Scout and the trader file at 1440 and 390 on a `harness/cli.ts up demo` stack before
and after the fixes. The live app was read through its api only (no clicks: it trades real money).
Two live reports from Julien the same morning folded in: "running what-if does nothing" and the "skipped"
rows of the day before.
